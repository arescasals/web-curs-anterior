# Sonsdebarri

Sonsdebarri és una web per a tots els públics on s'informa de pròxims events musicals en la ciutat de Lleida, en ella trobarem horaris, patrocinadors oficials i informació d'interès.

## Tecnologies utilitzades

- HTML
- CSS
- JavaScript

## Com obrir-la en local

1. Descarrega o clona aquest repositori.
2. Obre el fitxer `index.html` amb el navegador (doble clic).
